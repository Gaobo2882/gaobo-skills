**② 的两个坑（2026-09-27 实测）**：

- **`bsk` 命令必须绕开沙箱**，否则**无任何输出、直接被 SIGTERM 杀掉**（假象像"扩展没连"）。用 Bash 工具时带 `dangerouslyDisableSandbox`。
- **输出要重定向到文件再读**，别用 `| head` / `| tail` —— 管道同样会被 SIGTERM 掐掉。写成 `bsk status > out.txt 2>&1` 再 `cat`。
- **扩展掉线的真凶是 daemon 版本漂移**：状态里出现 `protocol ext 1.3 vs daemon 1.1` 时，daemon 会陷入自动升级重启循环（`uptime` 每次看都只有几秒），扩展连不上。处置：`bsk daemon stop` → `BSK_AUTO_UPDATE=off bsk daemon start` 把 daemon 稳住；**然后仍需高博点一下浏览器里的扩展图标重连**（这一步机器代劳不了）。
- 会话 id 只在**同一条命令**里有效时段内可用；daemon 一重启，旧 session 立刻 `session not registered`。**拿到 id 就紧接着用，别隔命令。**

## 🚫 第一条铁律（1.7 新增 · 违反即返工，不解释不辩解）

**文章正文里出现的每一张图，只能是真实截图。**

**禁止**（一个都不许出现）：

- ❌ **内嵌 SVG 自绘的示意图**——流程图、对比图、概念图、结构图、时间轴，一律算违规。**"我只是画个简单的流程图说明一下"不是理由。**
- ❌ AI 生成图 / 文生图 / 素材网站配图
- ❌ PIL / Python 画的线框图、假 UI、假界面
- ❌ 带"AI生成"水印的任何图

**允许**（只有这三种）：

1. ✅ 高博自己真实操作时截的图（手机 / 电脑，敏感信息先打码）
2. ✅ 公开实测文的真实截图（逐张核对画面，注明图源）
3. ✅ 官方帮助中心 / 官方发布页的界面图

**不是图片、不受此限的**：表格、清单卡、色块、加粗高亮等**原生 HTML 排版元素**。它们是排版手段，不是配图，可以放心用。

**唯一例外：封面。**封面按 **§4.1** 走——**AI 生成插画 + 确定性叠字，两层合成**，900×382。用图像生成积分前先跟高博报备（每张约 5-10 积分）。**注意这条不是"封面可以随便画"的口子**：封面上的文字仍然一个字都不许交给 AI，必须 PIL 精确叠加；封面也绝不许拿自绘 SVG 或假界面充数。

**为什么这条排在第一位**：配图是读者"照着做"的落脚点。自绘图 / 生成图看着漂亮，但它证明不了任何东西——它只说明"这一步我没真做过"。**拼不出真截图，就等于这一步没有实测依据。**

**交付前自查动作（硬性）**：在成稿 HTML 里搜 `&lt;svg` 和 `<img`，逐个确认来源；**除封面外不允许出现任何 `<svg`**。

**纪律四条（都是踩过的）**：

1. **不凭训练记忆答新闻**。拉不到就说拉不到，不许拿记忆里的旧消息冒充"今天的动态"。
2. **数字、政策、原话回第三方原文核对**才许写进候选（金额红线照旧：多源不一致就不出数字）。
3. **动态 ≠ 选题**。AI HOT 只提供「今天能干成哪件事的时机」，选题本身要问"我自己 / 带读者能做成哪件事"（见 §1.1 末尾的视角三问）。**光有一条新闻、没有可照做的动作，不是选题。**
4. **国产优先**。国外模型刷屏（GPT / Claude 系）不进候选池，按高博「尽量用国产工具，尽量不推国外工具」红线排除，但在榜里注明「本轮未用」，让高博知道动态全貌。

**两个实现坑（2026-09-28 实测，下次直接照做）**：

1. **本机 Python312 没有 `tzdata`**，`zoneinfo.ZoneInfo("Asia/Shanghai")` 会直接抛 `ZoneInfoNotFoundError`。**转北京时间别用它**，改用固定偏移：`from datetime import timezone, timedelta` + `tz = timezone(timedelta(hours=8))`。
2. **中文关键字必须走 `urllib.parse.quote`**，且要强制 IPv4 + 绕开系统代理（本机代理会干扰出网）——照抄下面这段就能用：

   ```python
   import json, socket, urllib.request
   _o = socket.getaddrinfo
   socket.getaddrinfo = lambda h,p,f=0,t=0,pr=0,fl=0: _o(h,p,socket.AF_INET,t,pr,fl)
   op = urllib.request.build_opener(urllib.request.ProxyHandler({}))
   req = urllib.request.Request(url)
   req.add_header("User-Agent", "aihot-skill/1.1.2 (+https://aihot.virxact.com/aihot-skill/)")
   data = json.loads(op.open(req, timeout=45).read().decode("utf-8"))
   ```

> 实测再次印证：**`mode=selected` 对国产冷门产品的覆盖很差**——2026-09-28 那轮，豆包 / 智谱 / 即梦 / 剪映 在精选池**全部返回空**，换 `mode=all` 才有内容。**"精选池空转全量池"这条不能省。**

**输出形态（硬性）**：候选池文件里必须有一节叫「时效输入」，形如：

```
### 时效输入（AI HOT，近 24h/7d）
- 国产：Qwen-Audio-3.1 五款语音模型 + 全线降价（9/23，三源）；Kimi 浏览器扩展可"录操作存 skill"（9/22）
- 海外刷屏（本轮未用）：GPT-6 Sol/Luna、Claude Opus 5.5 —— 按"不推国外工具"红线排除
```

**三条输入源，AI 讯息只是其中一条**（2026-09-06 高博校准）：

1. **AI 最新讯息**（AI HOT，本节）——提供时机。
2. **高博素材矿**——亲历真事 / 踩过的坑 / 手边工具 / 工作里的真实场景。**选题时先挖这一条**，它是零单源风险、永不撞车的独家来源。
3. **在途系列**——已开没写完的（如「每天AI一件事」「教爸妈用 AI」）。

**"新闻反应型"和"亲历实测型"应当五五开**。别整榜都是新闻。

### 1.0.5 痛点驱动：选题到底从哪来（2026-09-28 高博口述立规 · 位置在一切技巧之前）

> **高博原话（2026-09-28，逐字保留）**：「我觉得你要多去想一想，**AI 到底能帮我们普通人去解决什么样的问题**，不管是孩子呀、工作呀、老人呀，是吧？就是不同的人群，他到底有哪些这种痛点，**AI 刚好可以去精准解决的**。那么现在的 AI 更新换代这么快，**它每一次更新的功能都是什么，你们也要关注它更新的这些功能，就是所谓痛点**，那我们就可以拿出来就说的。**我不希望说这个标题只是说为了选题去做，而是说真的能解决有些人的痛点，然后别人看到了以后，刚好能产生共鸣，然后再展开去写**，我觉得这才是有意义的。」

**一句话**：**题不是"想"出来的，是「人群痛点 × AI 新能力」碰出来的。**

**两条输入，一头一尾**：

| 输入 | 内容 | 什么时候看 |
|---|---|---|
| **一头 · 人群痛点**（相对稳定） | 孩子 / 工作 / 老人 / 家里 / 自己 —— 每个群体反复头疼的那件事 | 维护成一张表，长期养 |
| **一尾 · AI 新能力**（变化极快） | **这次更新上了什么功能？这个功能精准解了谁的什么痛？** | **每次选题拉 AI HOT 时专门过一遍**（§1.0 的用法升级：不只找"时机"，更找"新能力压在哪条痛点上"） |

**选题三步**：

1. **列痛点**——各群体写 2–3 条真实反复的（不许写"谁都想要"的空话）
2. **对能力**——这次 AI 更新了什么、哪个新功能刚好压在某条痛点上（**新功能 = 新增的痛点清单**）
3. **查素材**——这件事**我有没有真做过**？有＝能写；没有＝要么亲手跑一遍，要么换题（§1.1 交叉点）

**这张矩阵要长期养**（每轮选题往里补，**不许每次从零想**）：

| 人群 | 反复头疼的事 | AI 现在能精准解吗 | 我有没有素材 |
|---|---|---|---|
| **孩子** | 问不停 / 学不会 / 坐不住 / 亲子时间不够 | | |
| **工作** | 材料写不完 / 数据理不清 / 重复活太多 / 汇报挤时间 | | |
| **老人** | 挂号 / 防骗 / 手机不会用 / 看不清说明书 / 说不清病情 | | |
| **家里** | 账算不清 / 照片视频堆成山 / 手续记不住 / 待办漏 | | |
| **自己** | 学不进去 / 拖着不动 / 信息过载 / 记不住事 | | |

**这道门比前面所有关卡都靠前**：**标题不是"为了选题"而做的** —— 把它念给一个真实的人听，他会不会"**这就是我的事**"？不会＝这条题不成立（接 §1.5 第一铁律：标题就是一句价值声明）。

> **和「独家性只能来自素材」怎么并存**：两者不冲突，是**一条链子上的三个环** ——
> **痛点（写什么）× AI 新能力（为什么是现在）→ 交集 → 我有没有素材（能不能写）**。
> **前三轮的错，全在跳过了最前面那一环**：直接从"我想得到的角度"出发，所以做出来的题既撞车（人人想得到），又跟读者无关（他不知道能拿走什么）。
> **一句话记住三个词：谁痛 → 现在谁能解 → 我做过没有。**

**🔴 实操提示（2026-09-28 第五轮实测）：新功能的"首发位"窗口极短，只有 2–3 天。**

从"AI 新功能"倒推痛点这条路**可行，但时效极紧**。9/28 第五轮把 9 月这波新功能逐条查重，结果是：

| 死法 | 实例 |
|---|---|
| **被媒体实测稿占掉** | 豆包工作「目标模式」（9/23 上线）→ 同题 ≥3 篇，含重庆晚报细粒度实测；千问「健康档案」（9/24）→ 已有完整实录 |
| **被官方自己的教程完胜** | WPS 批量生成文档 → WPS 官网自带邮件合并教程，第三方《几十张奖状逐个改名太折磨？》已把故事讲完 |
| **被下载站 SEO 做烂 + 未全量** | 蚂蚁灵光「闪应用」→ 搜到全是"怎么创建闪应用 1.2.3.4.5" |
| **老产品翻新** | 天工 AI MV（SkyMusic 早已升级 Mureka）、元宝旅游计划 Agent（新瓶装旧酒） |

**判据**：新功能上线后 **2–3 天内没人写实测，首发位就没了**；再晚连官方教程都来了。所以——
**要么在上线当天/次日就写"我拿它跑了一遍"，要么干脆别碰这个功能。** 15 条新功能里最后只剩 2 条可写（其中 1 条素材还不自足）。
> 反面教材：这轮唯一筛出的"首发位空着"的题（千问×夸克网盘，9/28 当天上线，4 篇报道全是媒体转述、无一篇实测），**恰恰因为它当天就该动笔**；而它同时踩了"素材待给"，所以仍没放行。

选题前必须核对三类资料，缺一项不动手：

- **选题库原文**：夸克网盘《热点选题库_2026Q3.md》，注意抓取日期，过期的 P0/P1 直接判死。
- **运营策略文档 + 团队共选记录**：本地缓存 `.workbuddy/cache/wbpage_JRisjrwd2sNBQK5hkbDvB7/docs/`。
- **已发稿坐标轴**：最近已发文章各是什么定位，新选题要接得上、不重复。

**视角三问（2026-09-06 高博追问后确立，比输入源更根本）**：每条候选题打分之前先过一遍，**答不上来就不许进榜**。

1. 主角是「莫何干成一件事」，还是「某产品有新动静」？
2. 读者读完是「知道了」，还是「今天就能照做」？
3. 是「替读者看」，还是「带读者干」？

> **根因**：视角错位 = 把自己当"AI 编辑部"（向上看厂商动态、挑名词话题来写、替读者看、用结论式全知标题）；该做的是"AI 学伴 / 搭子"（向内看手边资源、挑动词事情来干、带读者干、并且**老实承认哪几步要读者自己接手**、标题可以是探索式的"能不能…？"）。
> **收藏体质的真正来源是读者"照做成了"的成功体验，不是清单好看。**

**价值五问（多此一举 + 不难不做 · 2026-09-27 立前三问、2026-09-28 补第四、第五问）**：视角三问管的是"**谁在动手**"，管不了"**这动手值不值**"。打完视角三问，接着过这五问，**任何一问答不上来即毙，不进打分表**。

| # | 问 | 过不了的样子 |
|:---:|---|---|
| **1** | **不用 AI 的时候，这事我怎么干？** | 答"我本来就这么干、挺好" → **本来就挺好**，毙 |
| **2** | **用 AI 之后我具体省了什么、多得了什么？现成 App / 免费工具 / 直接自己干，能不能干得一样好？** | 被现成工具完胜 → 毙（例：月底截图变表格，银行 App 完胜） |
| **3** | **这句话我敢不敢当面对朋友说？** | 说不出口 → 毙（例："你用自己声音给娃读书吧"，当面说会被笑） |
| **4** | **把 AI 从这件事里去掉，这件事还成立吗？**（2026-09-28 新增） | 不成立 → **这个需求是我为 AI 造出来的**，毙 |
| **5** | **🔴 问一句 AI、拿一句答案，这件事就办成了吗？**（2026-09-28 新增 · 见下方「难题门槛」） | 能办成 → **这活太轻**，百度/豆包随手一问就有 → 毙 |

**🔴 难题门槛（价值第五问 · 2026-09-28 高博否掉整组候选后确立）**

> **高博原话（2026-09-28）**：「这种选题，可能是能让 AI 给你解决一个**难题**，或者说需要你自己去**不断地经过很多轮的对话、付出一些时间**，可能才能收获一些成果。如果说你只是**问一个问题、收获一个答案**，那这种没有什么意义呀。**那现在人随便去百度上面也可以做到**。」
> 同一次还说：「就看过去，**第一眼觉得这个标题就没有什么意义、没有什么可看的**。」（例：`AI 排的行程，出发前我用高德验了一遍` —— 验了一遍，**然后呢？** 例：`说不出的话，我让 AI 替我写` —— 写一遍，**能解决啥问题？**）

**判据只有一句话**：**不用 AI，这件事要花我多少时间？**
- 答"几分钟 / 一问就完 / 随手问一句" → **这活太轻，毙**。它不是选题，是个搜索词。
- 答"半天、一整晚、要反复改好几轮、要串好几步、要来回返工" → **这才是选题**。

**为什么这条排得这么靠后却这么关键**：前三问防"多此一举"、第四问防"无中生有"，**第五问防"活儿太轻"**。前三轮候选的死因全在这——`娃问为什么`（问一句就有答案）、`拍照看说明书`（拍一张就有答案）、`说不出口的话`（问一句就有答案）、`AI 排行程`（问一句就有一份行程）、`样片模式`（选个开关的事）。**它们全都有一个共同形状：一问一答。**

**难题的六种形态（对号入座用）**——可写的题，几乎都落在这六种里：

| # | 形态 | 特征 | 读者能带走什么 |
|:---:|---|---|---|
| 1 | **散 → 整** | 一堆零碎东西（几百张照片 / 一摞票据 / 几十个文件）要变成**一份能交出去的成品** | 整理流程 + 命名规范 + 成品模板 |
| 2 | **长 → 短** | 几十页的东西（合同 / 规则 / 说明书 / 报告）要读出一个**能拿去用的结论** | 提问框架 + 怎么验它有没有编 |
| 3 | **多点比较** | 几个方案 / 几家报价 / 几种做法，要摊开**算一算**再定 | 对比表 + 决策口径 |
| 4 | **多轮返工** | 一份东西要**改很多轮**才敢拿出去（简历 / 方案 / 文案） | 每轮该改什么 + 怎么判"能用了" |
| 5 | **重复自动化** | 每周 / 每月**都要重做一遍**的事 | 一条流水线 / 一次配好、以后免做 |
| 6 | **从零学做** | 不会的活儿（不懂剪辑 / 不懂表格 / 不懂做网站），要**跟着做出来** | 最短路径 + 卡点清单 |

> **反过来说**：凡是"问一句 → 答一句"就能收工的，六种形态一种都不沾，**一律判死**。

**🔴 可写题的交叉点（比五问更根上的定位）**：

**读者的同款难题 × 我的一手素材 —— 两头都占，才叫能写。**

| 情况 | 结果 | 例子 |
|---|---|---|
| 只有读者有难题、我没有素材 | **红海**（人人想得到、早被写光） | 娃问的为什么、看说明书、催款话术 |
| 只有我有素材、读者没这难题 | **私事**（读者无感，还容易踩身份红线） | 房产处置、审计整改、单位里的项目 |
| **两头都占** | ✅ **能写** | 家里的钱怎么算、陪娃真翻车的那一次、每周都要重做的家务式工作 |

> **这条解释了三轮候选为什么全灭**：要么落在第一行（红海），要么落在第二行（私事/红线），**没有一条站在交叉点上**。
> **所以正确的动作顺序是：先翻我手边的素材 → 找里面读者也有同款的那一件 → 那才是题。**

> **第四问的来历（2026-09-28 高博否掉候选①）**：候选①《国庆回家帮爸妈手机里装个 AI》三方一致第一（研究员 5.00／审稿 4.38／发布 4.67），高博一句"这有什么意义呢？我不知道吸引人的地方在哪里"直接否掉。
> 死因就是第四问：**老人真实的需求是"挂上号""别被骗""跟儿子视频清楚点"，从来没有"我要用 AI"** —— 去掉 AI，这件事根本不成立。而且我给它写的辩护（"能听懂挂号、识别诈骗短信"）恰恰是被**医院 App、微信小程序、国家反诈中心**完胜的，等于亲手踩了 §1.2 标准二「平台已免费覆盖的功能不是痛点」。
> 前三问防的是"**多此一举**"，第四问防的是"**无中生有**"。**先有浪漫画面、再从画面倒推需求**（我回家教爸妈用 AI，多孝顺）是这类错的标准形状——与 9/27 被否的「用自己声音给娃读书」完全同构。

> **另一条自查（视角真伪）**：候选的高分如果**全部来自情绪包装**（孝顺 / 团圆 / 感动 / 家族群转发），而内容本身说不出"能带走什么"，那么它是**传播分冒充价值分** —— 9/27 声音稿 4.80、9/28 候选① 三方一致第一，都是这么来的。**打分前先问一句：这条题去掉情绪包装后，还剩下什么？**

### 1.2 选题标准

**🔴 三词总纲（2026-09-28 高博亲口给的口径，置于四条标准之上）**：**对别人有用 · 有实用价值 · 有趣。**

> 高博原话：「重新选题吧，调整一下思路，要对别人有用。然后，有实用价值，有趣的这些选项。」
> 起因：候选①《帮爸妈装 AI》被否——它既不是"对别人有用"（老人本来不需要），也没有"实用价值"（装完没下文），更不"有趣"（只有一个孝顺画面）。

| 词 | 落成可执行的自问 |
|---|---|
| **对别人有用** | 出发点是**别人能得到什么**，不是我觉得新鲜。说不出"读者拿这条去干什么"，就不合格 |
| **有实用价值** | 读完**当天就能照做**，且手里**多了一样能带走的东西**（一段可复制的话 / 一张对照表 / 一条核对清单 / 一个已配好的设置） |
| **有趣** | 讲给朋友听，他会不会"哦？"一下。**有发现感、有意外、有反转**——不是又一篇干巴巴的操作步骤。**"有趣"不是搞笑，是读者愿意读下去、读完想转给别人** |

> **三词的关系**：有用是底线（不满足直接毙）；实用是收藏的理由；**有趣是点开的理由**。三条一起过，才是"值得做的题"。
> **反例（候选①）**：有用 ❌（老人不需要）｜实用 ❌（装完没下文）｜有趣 ❌（只有孝顺画面）。三词全不过，却拿了 36 分核弹级——**说明旧打分维度（情绪/传播/独家…）测不出这三样，必须单独立维**。

---

**四条细则（与三词总纲并行，不冲突）**：

**标准一：一篇只解决一个难题。** 不贪多，不堆砌功能。

**标准二：只打刚需，且先过痛点验证。** 瞄准真实反复遇到的难题；「可做可不做」不做；**平台/工具自带功能已免费解决的，不做**（先做这道验证再往下走）。

**标准三：必须答得出"比直接问豆包多了什么"。** 三种合法答案：持续自动化 / 专业深度 / 系统流程。答不出就淘汰。Agent 类优先，但不是唯一形态。

**标准四：人群二选一或交叉。** 职场人（含求职者、小业主）/ 老年人（数字鸿沟场景）。老年题材优先用高博在老年大学的一手观察。**注意**：老年题材的切入点必须是**他们真实卡住过的一件具体事**，不能是"教他们装/用某个 AI"（见 §1.1 价值第四问）。

辅助判断（运营策略）：实操教程为核心，给可照做的步骤 / 可复制的模板；认知趋势类已叫停；时令节点 + 具体人群 + 具体场景。

### 1.3 选题流水线

0. **先拉 AI 最新讯息**（§1.0，`aihot` skill），连同**素材矿**、**在途系列**三条线一起进候选池。每条候选按顺序过**四关**，过不了的直接丢掉、不进打分表：
   - **第零关 · 交叉点**（§1.1 末）：读者的同款难题 × 我的一手素材 —— 两头不占，直接不进池
   - **第一关 · 视角三问**（§1.1）：谁在动手
   - **第二关 · 价值五问**（§1.1）：这动手值不值 —— **第五问＝难题门槛：一问一答能办成 = 毙**
   - **第三关 · 三词总纲**（§1.2）：对别人有用 / 有实用价值 / 有趣 —— **任一答不上即毙**
   > ⚠️ **四关全过之前不许打分**。前三轮的错误就是"跳过第三、第四关直接进 8 维/9 维表"，结果**红海题拿高分、轻活拿高分**。**关是关，分是分，先过关再打分。**
0.5 **查重（2026-09-28 新增 · 硬性动作 · 必须真搜）**：过完三关的候选，**每条都要用 WebSearch 搜两件事，把搜索结果写进候选文件**：
   - **① 这个角度有没有人写过？** 用"账号会怎么写这条题"的关键词搜（例：`用AI回答孩子为什么 家长 豆包`）。同题 ≥3 篇 → **信息差判 0**，除非有**独家素材**（实测数据 / 真实截图 / 亲历细节）撑住。
   - **② 现成工具 / 官方产品有没有干过？** 尤其大厂 App（例：`拍照识别说明书 药盒 AI`）。**被官方产品完美覆盖 → 直接毙**（价值第二问塌）。

   **为什么单独立这一步**：9/28 候选池 v2 里我给每条候选都写了"现成替代为什么不行"一栏，**但一条都没真去搜** —— 纯属自说自话。真搜完的结果是：候选 A《娃的为什么》同题至少 5 篇、**连提问模板都被别人写出来了**；候选 B《拍一张看懂说明书》被**蚂蚁阿福官方"拍药盒"功能**（与中国药品监管数据中心合作）和百度健康"AI 用药说明书"完胜；候选 C《说不出口的话》被 CSDN 提示词包占掉。
   > **教训：「验证」必须是一个动作，不是文件里的一栏。** 今天连着两次同型错误（上一版的①我编了一段"反面校验"给它辩护；这一版我写了"现成替代不行"却没搜），**形状完全一样——看起来验证过，其实一个字没验**。

   **同时记住一条取材规律**：**独家性只能来自素材，不能来自角度。** 越是"听着温馨实用"的题越是红海（孩子的问题、看说明书、催款话术——零门槛，人人想得到）。**角度人人能想到，素材只有你有。** 所以查重撞车的候选，正确的修法不是换角度，是**问高博要件素材**。

0.6 **已判死的题不许换名重来（2026-09-28 新增 · 硬性动作）**：出候选前先翻**淘汰记录**，逐条比对——**换了名字、换了落点措辞、但内核没变的题，一律拦掉，不许当新候选进榜。**
   - 起因：第四轮候选 E《让 AI 出题考我一整轮》，就是第二轮已判死的 F《让 AI 当陪练练一本书》**换名版**，核心一处没改，混在新池子里又被审稿票捞出来。**不拦它，就会一直"判死—换名—再进榜"。**
   - **判据**：不是看名字像不像，是看**前置题（读者凭什么看长文）的答案有没有变**。答案还是同一个，就是同一条题。
   - **写候选池时必做**：每条候选后面标一行"**与淘汰记录比对：无重复 / 与第 N 轮 X 同题**"。
0.7 **素材验真（2026-09-28 第五轮新增 · 进打分前的最后一道门 · 硬性动作）**：候选进打分表前，**每条必须写明"这条的素材从哪来、作者拿得到吗"**，并标一个等级：

| 等级 | 判据 | 处置 |
|:---:|---|---|
| **A 自造** | **作者自己动手就能跑出来**（本机就能跑、成品本身就是唯一信源） | 最高优先，**零单源风险** |
| **B 在手** | 作者现有资产里就有（真事、真数据、真场景） | 可写，动笔前确认一次 |
| **C 待给** | 需要作者额外提供（某账号 / 设备 / 资料），或需外部放量 | **必须设"素材验真前置"**；拿不到即降备位，**不得用"人人都有"顶替一手素材** |
| **D 空** | 只能编（说不清素材从哪来） | **直接毙** |

> **为什么单独立这道门**：前四轮（含 9/28 的第五轮）败因全是"**题出了、素材是空的**"——A 等高博的网盘、C 等设备数据、D 等内测放量，**每条都在等别人给**。而**"自造"级的题把"素材空"这个病从源头消灭**：跑出来就是唯一信源、零单源风险、天然过"场景落地关"。
> **一句话判据**：**这条题，作者今天能不能自己动手把它做出来？** 能 → 优先；不能 → 排后面，或换题。
> **实操**：9/28 第五轮候选池 v4 里，4 条候选"推几条"三票第一次完全一致（只推 1 条），而**唯一被放行的就是自造级那一条**；评分最高的另一条（发布票 4.90）因为素材是"待给"，价值侧只给 3.00–3.50。

1. 候选池不少于 6 条，全部进 **9 维打分**（情绪 / 传播 / 独家 / 身份 / 时效 / 传播锚点 / 可视化 / 门槛 / **有趣度**，各 1-5 分，≥34 合格，≥39 核弹），**全表亮分**，不只给头部的分。
   - **有趣度单独立维（2026-09-28 高博要求）**：1 分＝干巴巴的操作步骤，没人愿意读完；5 分＝有发现感 / 意外 / 反转，读完想讲给别人听。
   - ⚠️ **情绪分高、有趣度却低 = 危险信号**：说明分数全来自情绪包装，不是内容本身。**候选①（帮爸妈装 AI）就是这么骗过 8 维表的**——情绪 5、传播 5、独家 5，实际内容为空。
2. 每条叠加 **风格匹配度评估**（对照 1.4 风格画像，说明哪里合、哪里不合）。
3. Top 3 按六要素展开（难题与痛点验证 / 比问豆包多了什么 / 内容核心简述 / 选择理由 / 传播锚点 / 标题候选），其余候选给一行评分 + 一句去向（排队 / 待素材 / 淘汰）。
4. 附**淘汰记录**：被淘汰的写明死因，防止复活。
5. 给出推荐排序和理由，等高博回字母拍板，**不替他决定**。
6. 高博否了全组，就按他的新反馈修正标准，**整组重跑**——不修补旧候选。

### 1.4 高博风格画像（选题匹配标尺）

- **形态**：实操教程向，读者照着能做完；拒绝认知鸡汤和功能罗列
- **视角**：第一人称真实场景（他自己的求职 / 报销 / 育儿 / 老年大学 / 房产处置），细节别人编不出来
- **语言**：小白口语化，禁黑话禁汇报腔；标题走反常识金句或强名词直给
- **结构**：系列化潜力优先（能做成"第 N 篇"的题加分，如教爸妈用 AI 系列）
- **传播**：三端适配（公众号长文 + 小红书步骤卡 + 短视频演示），有家族群 / 职场群转发链路加分
- **人群**：职场人（求职 / 办公 / 报销）+ 老年人（数字鸿沟）双池
- **赛道**：紧扣 AI 视频制作与 Agent 自动化主线，已发稿要能串成坐标轴

### 1.5 标题公式（2026-09-25 高博修正 · 09-28 高博第三次否标题后，加第一条铁律）

**🔴 第一条铁律 · 标题就是一句价值声明（2026-09-28 立，位置在一切规则之前）**

**标题首先要告诉别人两件事：① 你想说明的是什么事 ② 能给他带来什么价值、什么用途。**

> 高博原话（2026-09-28）：「你这个标题没有意义啊，别人一看能给他带来什么呢？**他都不知道你这篇文章要讲什么。**……你看了这个标题你都不知道能给我带来什么，能给我带来什么用途，**写这样的标题又有什么意义呢？你的标题首先要告诉别人你想说明的是什么事，能给别人带来什么价值，能给别人带来什么用途。**」
> 被否的两条：《我给自己搭的那条流水线，前五版全是废的》｜《教爸妈用手机，我摸出来的顺序跟教程不一样》—— **共同的病：两个都是"我的故事"，读者看不出跟自己有什么关系。**

**两问自检（标题定稿前必须都答得出）**：

| # | 问 | 答不出的样子 |
|:---:|---|---|
| **1** | **这是讲什么事的？** | ❌《我给自己搭的那条流水线……》——**什么流水线**？做内容、还是工厂？读者连领域都看不出 |
| **2** | **我看完能得到什么、拿它干什么？** | ❌《……前五版全是废的》——**你废你的，跟读者何干**？ |

**主语检测**：标题的主语是「我」，还是「读者要的那个东西」？

- ❌ 我的故事当标题：《我给自己搭的那条流水线，前五版全是废的》《家里的账我算了三遍》
- ✅ 改成读者视角：《做内容哪几步能交给 AI，哪几步它真干不了》《家里的长期账，怎么算清、怎么核对》

> **记法：**「我的过程」是**正文里的证据**，不是**标题里的卖点**。翻车、返工、代价，全部放进正文当证据链；标题只负责回答"讲什么、你能拿走什么"。

**⚠️ 反过来说，这也是一台检验器**：如果一条题**说不出一句"读者能得到什么"**，那不是标题没写好，是**这条题本身没有价值** —— 标题是检验器，不是包装纸。**改标题救不了一条本来就空的题。**

---

**其余可用形状**：强名词直给（如"Agent 实操教程：XXX"）｜福利 / 结论直说（"XX 又送 YY 了，快点来领"）｜反常识金句「你以为…其实…」｜对比反差｜自问自答｜避坑提醒。**关键点加粗，结论先行。**

**🚫 禁用（高博点名，同类一律不许）**：
- **"产品名 + 先拿它干这 N 件事"式**（2026-09-25）——把标题写成"领了 X 这 N 天，先拿它干这 3 件事""X 送你了，用它能干这 5 件事"这类**"数字 + 行动清单"复合体**。
- **一切以"……这 N 件事 / 这 N 个用法 / 这 N 招"结尾的清单式命题**，无论前面挂的是福利、工具还是教程。原话："不要再出现这样的话或同类别的意思"。
- **数字不许被拿来撑标题**。旧的"数字清单"公式作废。
- **🚫 动作落点（2026-09-28 增补）**：标题的落点**不许是一个动作**——装 / 下载 / 注册 / 开通 / 领取 / 上手 / 学会。必须落在**结果或那件具体的事**上。
  - ❌《国庆回家，帮爸妈手机里装个 AI》（落点是"装"，读者不知道装完能得到什么）
  - ✅《我爸妈手机里多了个能听懂的帮手》/《我妈拿着手机问我这行字什么意思，我让她自己拍了一张》（落点是"那件事"和"结果"）
  - **自检**：标题念完，能不能立刻回答"然后呢、我能得到什么"？答不出＝动作落点＝重起。
- **🚫 轻活标题（2026-09-28 高博增补 · 第一眼测试）**：标题里如果透出来的是**一件"一问就有答案"的小事**（问一句 / 拍一张 / 写一遍 / 验一遍 / 选一下），**一眼就该毙**。
  - 高博原话：「就看过去，**第一眼觉得这个标题就没有什么意义、没有什么可看的**。」
  - ❌《AI 排的行程，出发前我用高德验了一遍》——**验了一遍，然后呢？** 能带来什么？
  - ❌《说不出的话，我让 AI 替我写》——**写一遍，能解决啥问题？** 问一下豆包不就有？
  - ❌《娃问我为什么，我让 AI 讲了一遍》——一问一答，人人会。
  - **三秒测试（标题定稿前必过）**：把标题念给一个不认识你的人听，**他第一反应是"哦这个我得看"还是"这有什么好看的"？** 后者一律重起。
  - **正面形状**：标题要透出**"这里头有件麻烦事"** —— 有量（一堆东西）、有轮次（改了好几遍）、有代价（算了两天 / 试了四种）、有反转（第一个答案是错的）。
    - ✅《一堆照片里挑出能发家族群的，我理了一晚上》——有量、有代价
    - ✅《我让 AI 算了三遍家里的账，三遍数字都不一样》——有轮次、有反转
- **🚫 标题不得暴露身份（2026-09-28 增补，§7.2 的射程从正文扩到标题）**：标题里不许出现**职业 / 行业年限 / 单位性质 / 就业状态**。§7.2 原本只管正文，结果第四轮候选 A 的标题《我在老年大学教手机课……》直接被审稿票抓出来——**标题比正文更藏不住**，它是转发的第一行字。
  - ❌《我在老年大学教手机课，发现老人最先卡住的不是微信》——"在老年大学教课"= 暴露单位性质
  - ✅《教爸妈用手机，我摸出来的顺序跟教程写的不一样》——同样的内容，去身份
  - **自检**：标题里有没有"我在（某机构）""我们（某单位）""做了 N 年（某行业）"？有＝重起。

**取向**：简单直接优先。标题让人一眼知道"这东西是什么、我现在能得到什么"，不绕弯、不造悬念、不堆修辞。福利 / 时令类**可以直白喊行动**（"又送 30 天会员了，快点来领"）；工具 / 教程类走强名词直给。**注意边界**：标题能喊福利，正文主体不能也只剩通知，"能带走的东西"照旧要过。

## 二、成稿阶段

### 2.1 框架先行

动笔前先出框架（标题 + 各节要点 + 配图方案 + 风险自检），高博确认后才写正文。

### 2.2 写法规范

- 口语化，人人都能懂，禁机械排比、模板句、汇报腔；小标题像说话。
- 结论先行，小白通俗版，第一人称真实视角（高博自己的场景优先当素材）。
- 关键操作写成编号步骤卡，颗粒度到「照着点就行」：**菜单名加粗、路径写全**。
- 提示词做成可直接复制的整段。
- **段与段之间空一行留呼吸感。**
- 文末附参考来源块；不引导关注 / 订阅；不写死收益承诺数字。
- 涉及填报 / 支付的环节必写安全线：**登录自己来、验证码自己过、提交自己点**。

### 2.3 迭代纪律（实战教训沉淀）

| 高博的批评 | 对应动作 |
|---|---|
| 「只讲单点工具用法，看完没收获」 | 拆完整难题的全链路 |
| 「太宽泛，真想学的人看不懂 123456 步」 | 每步写到点击路径颗粒度，先讲清原理再给指令 |
| 「关键设置读者不会操作」 | 高频卡点必须配图，把读者当完全小白 |
| 「截图要用真实的」 | 配图铁律（见第三节） |
| 「图片必须用实际截图，不要用生成的图」（2026-09-23） | **零自绘图铁律**（见第〇节 + 3.1）：正文任何图形只许真实截图，自绘 SVG / 生成图一律删 |
| 「文档里写了，你怎么又犯了」 | 交付前必须重读本手册对应章节，**不凭记忆执行** |
| 「痛点是平台已解决的功能」 | 痛点验证前置（见 1.2） |
| 「那段时间我想明白一件事」 | 叙事腔套话，禁用清单见 7.1 |
| 「文章透露了我的职业 / 失业状态」 | 身份隐身红线，见 7.2 |
| 「发给 AI 谁都会，没价值」 | 专精工具推荐规范，见 7.3 |

**每轮批评先复述确认理解，再动手改，不辩解。**

## 三、配图阶段（铁律，永久有效）

### 3.1 素材规则（1.7 加严：从"禁假界面"扩展到"禁一切自绘图"）

- **正文里每一张图，只能用真实截图。** 这条覆盖**所有**图形：不只界面图，**流程图、对比图、概念图、结构图、时间轴、自绘 SVG 一律不许出现**。
  - 1.6 及以前的漏洞：只写了"禁自己生成**界面**示意图（PIL 线框图、假 UI）"，结果自绘的"流程图 / 对比图"被当成排版混进成稿。**1.7 明确堵死：自己画的图就是自己画的图，换个形式也不行。**
- **要图，只能去拿真图**，不能去造图：拿不到就按下面的图源优先级找，找不到就给高博「自拍截图清单」。
- 截图必须穿插到文章对应步骤位置，不许文末堆素材，**不许留占位符当完成**。
- **图源优先级**：① 高博自己实拍（敏感信息先打码）→ ② 公开实测文引用并注明图源 → ③ 官方帮助中心 / 官方发布页界面图。
- 找不到图时给高博「自拍截图清单」：标明拍哪个界面、圈哪里、注意什么。**宁可该段无图，也不许自绘一张顶上。**
- 抓教程图逐张目检：**带"AI生成"水印的一律弃用**。
- **原生 HTML 排版元素（表格 / 清单卡 / 色块 / 高亮）不算图片**，不占图位也不受本规则限制——需要视觉分隔就用它们，不要用 SVG。

### 3.5 零自绘图自查（1.7 新增·交付前必跑）

1. 在成稿 HTML 里搜 `&lt;svg`：**除封面外命中即为违规**，直接删。
2. 搜 `<img`：逐个确认是不是真实截图，有没有生成图 / 素材站图混进来。
3. 搜 `示意图` / `对比图` / `流程图` / `画一张`：确认没有"我画一张给你看"的段落。
4. 通读一遍，对每一张图问一句：**"这张图能不能证明我真做过这一步？"** 答不上来 → 删。

> 无图不丢人，假图毁账号。读者照着一张假图去点，点不到，这篇就废了。

### 3.2 图文匹配三问检查

交付前对**每一张插图**人工过三问，任一问答不上来就不许交付：

1. **画面里实际是什么？** 逐张目检，图上出现的文字、标签、按钮名要看得清清楚楚（OCR 级别）。
2. **图说说的是什么？** 图说必须如实描述画面，不许暗示画面里不存在的内容（画面是 A 专家，图说不许写得像 B 专家）。
3. **图和段落主题对不对得上？** 若图只是演示机制（如"召唤流程示意"），图说必须明示「示意 / 示例」并写清图中实际对象。

**硬约束（1.6 新增）**：

- 三问任一不过 → **只能换图或删图，禁止用"示意 / 示例"标注豁免**。"示意"只允许豁免视角、排版、演示账号差异，**不允许豁免画面主体错误**（段落写 A 专家、图里是 B 专家 = 主体错误，必须换 / 删）。
- 找图验收标准：**图上 OCR 级文字与段落对象一致**（段落写职业规划师，图里必须看得见"职业规划师"字样）。
- 引用他文截图：**逐张核对画面主体**，不凭文章标题或上下文推断图的内容。
- 找不到匹配的真实截图时：宁可该段无图，或给高博自拍清单，**不凑数**。

### 3.3 证据等级写作规则

写专家 / 功能名称必须有证据等级意识：

- **实锤**（有真实界面截图 + 实测记录）→ 可写使用细节
- **官方文字提及**（官方教程 / 文档列出但无实测）→ 只按官方简介口径写，不编使用体验
- **查无实证** → 不写

禁止把转述写成亲历口吻（"简介写得很明白"这种像是自己点开看过的表述，在只有二手来源时禁用）。

### 3.4 交付前强制自检（脚本卡死）

运行 `check_article_images.py`（工作区根目录）：扫全文有无占位标记、每张引用图片是否真实存在。**任何一项不过禁止交付**，以脚本 PASS 为准。

### 4.1 封面制作（分层精修 · 2026-09-27 高博定案）

**铁律：封面必须是「AI 生成插画 + 确定性叠字」两层合成。不许再用 PIL 画纯色块交差。**

> 2026-09-27 高博原话："每次封面做得太差劲了，封面你就用那个最好的这种技能去把这个封面做做做得好看一点。"
> 当时那版封面是 PIL 画的几何色块 + 文字，**一点画面都没有**，被判不合格。手册原先只写了"Q 版暖色系插画"七个字，等于没约束，所以这次要写死。

**为什么必须分两层**：AI 生图画质好，但**写中文标题会错字**，错一个字整张封面就废。
所以——**画面交给 AI，文字永远由 PIL 精确叠加，文字层绝不经 AI 之手。**
方法论出处：`ai-content-production` 技能包的「发布级精修」(Generative Polish)，核心就是"确定性层 + 生成层分离"。

**流程**：

1. **先报备**：`ImageGen` 每张图消耗约 **5-10 积分**。动手前必须先跟高博说一声再花，不许闷声刷图。
2. **出底图（生成层）**：用 `ImageGen`，参数 `size="1536x1024"`、`quality="high"`。
   Prompt 三要素，缺一不可：
   - **主体放一侧，另一侧留大片干净负空间**（标题要叠在留白那侧）。例：主体放右、留白在左。
   - **写明「画面中绝对不要出现任何文字、字母、汉字、数字、符号、水印或标志」**。
   - **写明「画面上下边缘都是可以安全裁切的纯色渐变」**，因为后面要裁成 2.35:1。
   - 风格锚定词固定：`Q 版暖色系扁平插画` + `圆润粗描边` + `赛璐璐平涂` + `温暖治愈有生活气息`；配色奶油米白打底、温暖橘黄与珊瑚橙为主、点缀少量清澈湖蓝。
3. **裁切**：底图裁成 **2.35:1**（落 900×382）。裁切**锚定顶部**、下移余量控制在 40px 以内，保住主体完整。
   **AI 出图自带的「AI生成」角标靠裁切整条切掉；严禁涂抹、马赛克、色块遮盖**——遮盖法定标识等于伪造。
4. **加可读性遮罩**：文字那一侧铺一层「米白 → 透明」水平渐变（实心段约占画布 34%，到 62% 处全透明）。不铺的话文字压在插画上对比度不够，手机上一眼就糊。
5. **确定性叠字（精确层）**。配色基线：深蓝 `#2E6FB5` / 黄 `#F5C842` / 米白 `#FAF8F2` / 黄块上深棕字 `#3A2A00`。
   **2× 超采样排版后 LANCZOS 降采样**，文字边缘才不毛。
   一版已验证可用的起始坐标（900×382，左边距 46）：

   | 元素 | 字号 | 位置 |
   |---|---|---|
   | 黄标（栏目 / 主题标签） | 21 粗 | y=46，黄色圆角条 |
   | 主标题第一行 | 46 粗 | y=106，深蓝 |
   | 主标题第二行 | 46 粗 | y=168，黄底块 + 深棕字 |
   | 底部小字（覆盖的场景点） | 18 常规 | y=302，深灰 `#58544C` |

6. **越界自检**：脚本里打印每个元素的右边界，**超过 892（=900-8）就算超界**，回去缩字号或挪位置。不许靠肉眼判断。
7. **落盘 `output/cover.png`**，等推送脚本按 §5.2 取用。

**脚本**：`_work/gen_cover_v2.py`（分层版，含遮罩与越界自检）。
旧版 `_work/gen_cover_v1_pil_backup.py`（纯 PIL 色块版）**已废弃，不要再拿来用**。

## 七、硬红线速查（1.1–1.6 沉淀，违反即返工）

### 7.1 禁用叙事腔套话清单（永久禁止）

以下句式永久禁止出现在文章里（AI 味转折模板，读者一眼假）：

- 「那段时间我想明白一件事」
- 「后来我才发现」「直到某一天」「那一刻我突然明白」「也就是从那时起」
- 一切"先讲故事再喊转折口号"的句式

**替换原则**：转折不喊口号，直接说事。口语化替换（如"说白了""其实"），或者干脆删掉转折让场景自己说话。**每篇成稿后全文扫一遍本清单。**

### 7.2 身份隐身红线（成稿硬约束）

文章里**不得透露作者的具体职业、行业年限、单位性质、就业状态**（在职 / 失业一律不写）。

读者群默认是"准备换工作的人 + 正在找工作的人"两大群，不许窄化成某一类。第一人称保留但去身份化：钩子段优先用第二人称场景（"你有没有过这种时候"），让读者对号入座；个人案例只保留"通用经历"，抹掉一切能定位到本人的信息。

### 7.3 专精工具推荐规范（独家性新来源）

「发给 AI 谁都会」不是价值，「哪个 AI 在哪件事上最强」才是。

凡是通用 AI 都能做的场景，动笔前必须调研"哪个 AI 在这件事上有特长"，文章给读者一张「场景 → 最强工具」地图 + 真实截图。

**优先顺序**：① WorkBuddy 专家中心（读者装了就有的专家系统，简历 / 面试 / 职业规划各有专精专家，截图由高博实拍打码）② 外部专精工具（须有 2026 年实测依据，注明来源）。

**反例**：只说"把简历发给 AI 让它改" = 谁都会 = 没价值。

### 7.4 痛点验证前置

选题先问"真正的难是什么、平台 / 工具自己解决了没有"。**平台已免费覆盖的功能不是痛点**（反例：求职进度提醒——各招聘平台自带，做了没价值）。痛点要挖到工具够不着的地方（正例：岗位匹配、经验迁移、动手代劳、面试陪练）。

### 7.5 Agent 是首选形态，不是硬门槛

主题是"AI 解决难题"，判断标准统一为一句话：**比直接问豆包多了什么**。

多出来的可以是三种之一：① 持续自动化（Agent / 定时任务 / 流水线）② 专业深度（数据、知识、识图、结构化产出）③ 系统流程（多步骤串联成一条路）。**占一条即成立；单次问答且无专业深度的才淘汰。**

### 7.6 人群池

① 想学 AI 的职场人 / 小业主 ② 老年人（数字鸿沟刚需：挂号、防骗、手机操作、政务办事）。高博任职老年大学，有一手场景素材，优先用。
