## 一、选题阶段

### 1.1 先读内容方向，再谈选题

选题前必须核对三类资料，缺一项不动手：

- **选题库原文**：夸克网盘《热点选题库_2026Q3.md》，注意抓取日期，过期的 P0/P1 直接判死。
- **运营策略文档 + 团队共选记录**：本地缓存 `.workbuddy/cache/wbpage_JRisjrwd2sNBQK5hkbDvB7/docs/`。
- **已发稿坐标轴**：最近已发文章各是什么定位，新选题要接得上、不重复。

### 1.2 选题标准

**标准一：一篇只解决一个难题。** 不贪多，不堆砌功能。

**标准二：只打刚需，且先过痛点验证。** 瞄准真实反复遇到的难题；「可做可不做」不做；**平台/工具自带功能已免费解决的，不做**（先做这道验证再往下走）。

**标准三：必须答得出"比直接问豆包多了什么"。** 三种合法答案：持续自动化 / 专业深度 / 系统流程。答不出就淘汰。Agent 类优先，但不是唯一形态。

**标准四：人群二选一或交叉。** 职场人（含求职者、小业主）/ 老年人（数字鸿沟场景）。老年题材优先用高博在老年大学的一手观察。

辅助判断（运营策略）：实操教程为核心，给可照做的步骤 / 可复制的模板；认知趋势类已叫停；时令节点 + 具体人群 + 具体场景。

### 1.3 选题流水线

1. 候选池不少于 6 条，全部进 **8 维打分**（情绪 / 传播 / 独家 / 身份 / 时效 / 传播锚点 / 可视化 / 门槛，各 1-5 分，≥30 合格，≥35 核弹），**全表亮分**，不只给头部的分。
2. 每条叠加 **风格匹配度评估**（对照 1.4 风格画像，说明哪里合、哪里不合）。
3. Top 3 按六要素展开（难题与痛点验证 / 比问豆包多了什么 / 内容核心简述 / 选择理由 / 传播锚点 / 标题候选），其余候选给一行评分 + 一句去向（排队 / 待素材 / 淘汰）。
4. 附**淘汰记录**：被淘汰的写明死因，防止复活。
5. 给出推荐排序和理由，等高博回字母拍板，**不替他决定**。
6. 高博否了全组，就按他的新反馈修正标准，**整组重跑**——不修补旧候选。

### 1.4 高博风格画像（选题匹配标尺）

- **形态**：实操教程向，读者照着能做完；拒绝认知鸡汤和功能罗列
- **视角**：第一人称真实场景（他自己的求职 / 报销 / 育儿 / 老年大学 / 房产处置），细节别人编不出来
- **语言**：小白口语化，禁黑话禁汇报腔；标题走反常识金句或强名词直给
- **结构**：系列化潜力优先（能做成"第 N 篇"的题加分，如教爸妈用 AI 系列）
- **传播**：三端适配（公众号长文 + 小红书步骤卡 + 短视频演示），有家族群 / 职场群转发链路加分
- **人群**：职场人（求职 / 办公 / 报销）+ 老年人（数字鸿沟）双池
- **赛道**：紧扣 AI 视频制作与 Agent 自动化主线，已发稿要能串成坐标轴

### 1.5 标题公式（已验证可用）

反常识金句「你以为…其实…」｜数字清单｜对比反差｜自问自答｜内幕 / 优越｜避坑｜强名词直给（如"Agent 实操教程：XXX"）。**关键点加粗，结论先行。**

## 二、成稿阶段

### 2.1 框架先行

动笔前先出框架（标题 + 各节要点 + 配图方案 + 风险自检），高博确认后才写正文。

### 2.2 写法规范

- 口语化，人人都能懂，禁机械排比、模板句、汇报腔；小标题像说话。
- 结论先行，小白通俗版，第一人称真实视角（高博自己的场景优先当素材）。
- 关键操作写成编号步骤卡，颗粒度到「照着点就行」：**菜单名加粗、路径写全**。
- 提示词做成可直接复制的整段。
- **段与段之间空一行留呼吸感。**
- 文末附参考来源块；不引导关注 / 订阅；不写死收益承诺数字。
- 涉及填报 / 支付的环节必写安全线：**登录自己来、验证码自己过、提交自己点**。

### 2.3 迭代纪律（实战教训沉淀）

| 高博的批评 | 对应动作 |
|---|---|
| 「只讲单点工具用法，看完没收获」 | 拆完整难题的全链路 |
| 「太宽泛，真想学的人看不懂 123456 步」 | 每步写到点击路径颗粒度，先讲清原理再给指令 |
| 「关键设置读者不会操作」 | 高频卡点必须配图，把读者当完全小白 |
| 「截图要用真实的」 | 配图铁律（见第三节） |
| 「痛点是平台已解决的功能」 | 痛点验证前置（见 1.2） |
| 「那段时间我想明白一件事」 | 叙事腔套话，禁用清单见 7.1 |
| 「文章透露了我的职业 / 失业状态」 | 身份隐身红线，见 7.2 |
| 「发给 AI 谁都会，没价值」 | 专精工具推荐规范，见 7.3 |

**每轮批评先复述确认理解，再动手改，不辩解。**

## 三、配图阶段（铁律，永久有效）

### 3.1 素材规则

- **只用真实软件操作截图**，绝不自己生成界面示意图（PIL 画的线框图、假 UI 一律禁用）。
- 截图必须穿插到文章对应步骤位置，不许文末堆素材，**不许留占位符当完成**。
- **图源优先级**：① 高博自己实拍（敏感信息先打码）→ ② 公开实测文引用并注明图源 → ③ 官方帮助中心界面图。
- 找不到图时给高博「自拍截图清单」：标明拍哪个界面、圈哪里、注意什么。
- 抓教程图逐张目检：**带"AI生成"水印的一律弃用**。

### 3.2 图文匹配三问检查

交付前对**每一张插图**人工过三问，任一问答不上来就不许交付：

1. **画面里实际是什么？** 逐张目检，图上出现的文字、标签、按钮名要看得清清楚楚（OCR 级别）。
2. **图说说的是什么？** 图说必须如实描述画面，不许暗示画面里不存在的内容（画面是 A 专家，图说不许写得像 B 专家）。
3. **图和段落主题对不对得上？** 若图只是演示机制（如"召唤流程示意"），图说必须明示「示意 / 示例」并写清图中实际对象。

**硬约束（1.6 新增）**：

- 三问任一不过 → **只能换图或删图，禁止用"示意 / 示例"标注豁免**。"示意"只允许豁免视角、排版、演示账号差异，**不允许豁免画面主体错误**（段落写 A 专家、图里是 B 专家 = 主体错误，必须换 / 删）。
- 找图验收标准：**图上 OCR 级文字与段落对象一致**（段落写职业规划师，图里必须看得见"职业规划师"字样）。
- 引用他文截图：**逐张核对画面主体**，不凭文章标题或上下文推断图的内容。
- 找不到匹配的真实截图时：宁可该段无图，或给高博自拍清单，**不凑数**。

### 3.3 证据等级写作规则

写专家 / 功能名称必须有证据等级意识：

- **实锤**（有真实界面截图 + 实测记录）→ 可写使用细节
- **官方文字提及**（官方教程 / 文档列出但无实测）→ 只按官方简介口径写，不编使用体验
- **查无实证** → 不写

禁止把转述写成亲历口吻（"简介写得很明白"这种像是自己点开看过的表述，在只有二手来源时禁用）。

### 3.4 交付前强制自检（脚本卡死）

运行 `check_article_images.py`（工作区根目录）：扫全文有无占位标记、每张引用图片是否真实存在。**任何一项不过禁止交付**，以脚本 PASS 为准。

## 七、硬红线速查（1.1–1.6 沉淀，违反即返工）

### 7.1 禁用叙事腔套话清单（永久禁止）

以下句式永久禁止出现在文章里（AI 味转折模板，读者一眼假）：

- 「那段时间我想明白一件事」
- 「后来我才发现」「直到某一天」「那一刻我突然明白」「也就是从那时起」
- 一切"先讲故事再喊转折口号"的句式

**替换原则**：转折不喊口号，直接说事。口语化替换（如"说白了""其实"），或者干脆删掉转折让场景自己说话。**每篇成稿后全文扫一遍本清单。**

### 7.2 身份隐身红线（成稿硬约束）

文章里**不得透露作者的具体职业、行业年限、单位性质、就业状态**（在职 / 失业一律不写）。

读者群默认是"准备换工作的人 + 正在找工作的人"两大群，不许窄化成某一类。第一人称保留但去身份化：钩子段优先用第二人称场景（"你有没有过这种时候"），让读者对号入座；个人案例只保留"通用经历"，抹掉一切能定位到本人的信息。

### 7.3 专精工具推荐规范（独家性新来源）

「发给 AI 谁都会」不是价值，「哪个 AI 在哪件事上最强」才是。

凡是通用 AI 都能做的场景，动笔前必须调研"哪个 AI 在这件事上有特长"，文章给读者一张「场景 → 最强工具」地图 + 真实截图。

**优先顺序**：① WorkBuddy 专家中心（读者装了就有的专家系统，简历 / 面试 / 职业规划各有专精专家，截图由高博实拍打码）② 外部专精工具（须有 2026 年实测依据，注明来源）。

**反例**：只说"把简历发给 AI 让它改" = 谁都会 = 没价值。

### 7.4 痛点验证前置

选题先问"真正的难是什么、平台 / 工具自己解决了没有"。**平台已免费覆盖的功能不是痛点**（反例：求职进度提醒——各招聘平台自带，做了没价值）。痛点要挖到工具够不着的地方（正例：岗位匹配、经验迁移、动手代劳、面试陪练）。

### 7.5 Agent 是首选形态，不是硬门槛

主题是"AI 解决难题"，判断标准统一为一句话：**比直接问豆包多了什么**。

多出来的可以是三种之一：① 持续自动化（Agent / 定时任务 / 流水线）② 专业深度（数据、知识、识图、结构化产出）③ 系统流程（多步骤串联成一条路）。**占一条即成立；单次问答且无专业深度的才淘汰。**

### 7.6 人群池

① 想学 AI 的职场人 / 小业主 ② 老年人（数字鸿沟刚需：挂号、防骗、手机操作、政务办事）。高博任职老年大学，有一手场景素材，优先用。
