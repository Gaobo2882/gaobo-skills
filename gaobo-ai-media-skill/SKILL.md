**⚠️ 已知卡点与三条通路（2026-09-27 二次实测，1.8.2 改写）**

**先说结论：连接器这条路走不通，别再让高博去加权限了。** 本机接的 GitHub 连接器是 **GitHub Copilot 托管 MCP**（`https://api.githubcopilot.com/mcp/`），它的 token 是 GitHub 侧签发的 App 安装令牌，**权限由 GitHub 固定，高博在界面上没有"补 Contents: Read and write"这个开关**。2026-09-27 高博重新登录授权后再试，仍是同一句：

```
403 Resource not accessible by integration
```

（判据：错误说 `by integration` = App 令牌；PAT 会明说 `by personal access token`。）本机也**没有 git 仓库、没有 `.git-credentials`、没有环境变量 PAT**，没有本地退路。

**真正能用的三条通路，按可靠性排序**：

| # | 通路 | 怎么做 | 稳定性 |
|:---:|---|---|---|
| ① | **classic PAT + 脚本**（首选） | 高博给一次 PAT（勾 `repo`），跑 `_gh_dl/push_to_github.py <PAT>`，**自带回读校验**（比字节数 + 查 5 个锚点） | ★★★ 一次性配好可长期复用 |
| ② | **浏览器直传** | 用 `browser-skill` 驱动已登录的浏览器打开 `github.com/<owner>/<repo>/edit/<branch>/<path>`，粘贴 + Commit | ★★ 依赖扩展在线 |
| ③ | **手动粘贴**（兜底） | 把内容写进**系统剪贴板**，让高博开 edit 页 → `Ctrl+A` → `Ctrl+V` → Commit | ★★★ 纯人工，30 秒 |

**③ 的剪贴板准备（一行搞定）**：

```powershell
$p = "C:\Users\Administrator\.workbuddy\skills\gaobo-ai-media-skill\SKILL.md"
Set-Clipboard -Value ([System.IO.File]::ReadAllText($p, [System.Text.Encoding]::UTF8))
```

**② 的两个坑（2026-09-27 实测）**：

- **`bsk` 命令必须绕开沙箱**，否则**无任何输出、直接被 SIGTERM 杀掉**（假象像"扩展没连"）。用 Bash 工具时带 `dangerouslyDisableSandbox`。
- **输出要重定向到文件再读**，别用 `| head` / `| tail` —— 管道同样会被 SIGTERM 掐掉。写成 `bsk status > out.txt 2>&1` 再 `cat`。
- **扩展掉线的真凶是 daemon 版本漂移**：状态里出现 `protocol ext 1.3 vs daemon 1.1` 时，daemon 会陷入自动升级重启循环（`uptime` 每次看都只有几秒），扩展连不上。处置：`bsk daemon stop` → `BSK_AUTO_UPDATE=off bsk daemon start` 把 daemon 稳住；**然后仍需高博点一下浏览器里的扩展图标重连**（这一步机器代劳不了）。
- 会话 id 只在**同一条命令**里有效时段内可用；daemon 一重启，旧 session 立刻 `session not registered`。**拿到 id 就紧接着用，别隔命令。**

→ 推不上去时**必须当场告诉高博**，说清三件事：① 卡在哪（403 原文）；② 内容已备好（三本地副本 + 剪贴板）；③ 让他选①/②/③哪条路。
→ **不许默默跳过，更不许谎报"已同步"。** 本地三份也要照常对齐，别因为推不上去就连本地都不改。

## 🚫 第一条铁律（1.7 新增 · 违反即返工，不解释不辩解）

**文章正文里出现的每一张图，只能是真实截图。**

**禁止**（一个都不许出现）：

- ❌ **内嵌 SVG 自绘的示意图**——流程图、对比图、概念图、结构图、时间轴，一律算违规。**"我只是画个简单的流程图说明一下"不是理由。**
- ❌ AI 生成图 / 文生图 / 素材网站配图
- ❌ PIL / Python 画的线框图、假 UI、假界面
- ❌ 带"AI生成"水印的任何图

**允许**（只有这三种）：

1. ✅ 高博自己真实操作时截的图（手机 / 电脑，敏感信息先打码）
2. ✅ 公开实测文的真实截图（逐张核对画面，注明图源）
3. ✅ 官方帮助中心 / 官方发布页的界面图

**不是图片、不受此限的**：表格、清单卡、色块、加粗高亮等**原生 HTML 排版元素**。它们是排版手段，不是配图，可以放心用。

**唯一例外：封面。**封面按 **§4.1** 走——**AI 生成插画 + 确定性叠字，两层合成**，900×382。用图像生成积分前先跟高博报备（每张约 5-10 积分）。**注意这条不是"封面可以随便画"的口子**：封面上的文字仍然一个字都不许交给 AI，必须 PIL 精确叠加；封面也绝不许拿自绘 SVG 或假界面充数。

**为什么这条排在第一位**：配图是读者"照着做"的落脚点。自绘图 / 生成图看着漂亮，但它证明不了任何东西——它只说明"这一步我没真做过"。**拼不出真截图，就等于这一步没有实测依据。**

**交付前自查动作（硬性）**：在成稿 HTML 里搜 `&lt;svg` 和 `<img`，逐个确认来源；**除封面外不允许出现任何 `<svg`**。

### 1.0 AI 最新讯息输入（选题第一步 · 2026-09-27 正式立节）

**只要高博说「选题」，第一步就是拉一份最新的 AI 讯息。不许凭记忆出候选，不许沿用上次的素材池。**

> **这条流程 2026-08-19 就定下了，但一直只躺在记忆里、没写进手册** —— 这次高博点名要补：「选题的这个 skill 里面要加入 AI 的一些最新的讯息的内容，要加这个版块进去。」
> 起因是 8/19 那天他一句「你这个完全不行，按照最新的 AI 动态看看」把稿子打回，当天定下的流程是：
> **先查最新 AI 动态 → 找当天最匹配账号的热点 → 给选题方案 + 标题候选 + 自评 5 关预检 → 高博拍板 → 写稿。**

**用什么拉**：加载 **`aihot` skill**（走 AI HOT 匿名只读 API，不需要 Key）。按意图选入口：

| 要什么 | 请求 |
|---|---|
| 今天 / 近 24 小时 | `/api/v1/items?mode=selected&window=24h` |
| 近一周 | `/api/v1/items?mode=selected&window=7d&limit=10` |
| 当前最热 | `/api/v1/hot-topics` |
| 日报 | `/api/v1/dailies/latest` |
| 关键词（公司 / 产品 / 主题） | `/api/v1/items?mode=selected&q=<关键词>&window=7d` |
| 精选池查不到时 | 用**完全相同**的参数再查一次 `mode=all` |

> 精选池是高门槛策展，冷门公司 / 早期产品常常只在全量池里有。**精选池空了先别报"没有"，换 `mode=all` 再查一遍**，并注明这些「未进入精选」。两次都空才算没找到。

**纪律四条（都是踩过的）**：

1. **不凭训练记忆答新闻**。拉不到就说拉不到，不许拿记忆里的旧消息冒充"今天的动态"。
2. **数字、政策、原话回第三方原文核对**才许写进候选（金额红线照旧：多源不一致就不出数字）。
3. **动态 ≠ 选题**。AI HOT 只提供「今天能干成哪件事的时机」，选题本身要问"我自己 / 带读者能做成哪件事"（见 §1.1 末尾的视角三问）。**光有一条新闻、没有可照做的动作，不是选题。**
4. **国产优先**。国外模型刷屏（GPT / Claude 系）不进候选池，按高博「尽量用国产工具，尽量不推国外工具」红线排除，但在榜里注明「本轮未用」，让高博知道动态全貌。

**输出形态（硬性）**：候选池文件里必须有一节叫「时效输入」，形如：

```
### 时效输入（AI HOT，近 24h/7d）
- 国产：Qwen-Audio-3.1 五款语音模型 + 全线降价（9/23，三源）；Kimi 浏览器扩展可"录操作存 skill"（9/22）
- 海外刷屏（本轮未用）：GPT-6 Sol/Luna、Claude Opus 5.5 —— 按"不推国外工具"红线排除
```

**三条输入源，AI 讯息只是其中一条**（2026-09-06 高博校准）：

1. **AI 最新讯息**（AI HOT，本节）——提供时机。
2. **高博素材矿**——亲历真事 / 踩过的坑 / 手边工具 / 工作里的真实场景。**选题时先挖这一条**，它是零单源风险、永不撞车的独家来源。
3. **在途系列**——已开没写完的（如「每天AI一件事」「教爸妈用 AI」）。

**"新闻反应型"和"亲历实测型"应当五五开**。别整榜都是新闻。

### 1.1 先读内容方向，再谈选题

选题前必须核对三类资料，缺一项不动手：

- **选题库原文**：夸克网盘《热点选题库_2026Q3.md》，注意抓取日期，过期的 P0/P1 直接判死。
- **运营策略文档 + 团队共选记录**：本地缓存 `.workbuddy/cache/wbpage_JRisjrwd2sNBQK5hkbDvB7/docs/`。
- **已发稿坐标轴**：最近已发文章各是什么定位，新选题要接得上、不重复。

**视角三问（2026-09-06 高博追问后确立，比输入源更根本）**：每条候选题打分之前先过一遍，**答不上来就不许进榜**。

1. 主角是「莫何干成一件事」，还是「某产品有新动静」？
2. 读者读完是「知道了」，还是「今天就能照做」？
3. 是「替读者看」，还是「带读者干」？

> **根因**：视角错位 = 把自己当"AI 编辑部"（向上看厂商动态、挑名词话题来写、替读者看、用结论式全知标题）；该做的是"AI 学伴 / 搭子"（向内看手边资源、挑动词事情来干、带读者干、并且**老实承认哪几步要读者自己接手**、标题可以是探索式的"能不能…？"）。
> **收藏体质的真正来源是读者"照做成了"的成功体验，不是清单好看。**

### 1.2 选题标准

**标准一：一篇只解决一个难题。** 不贪多，不堆砌功能。

**标准二：只打刚需，且先过痛点验证。** 瞄准真实反复遇到的难题；「可做可不做」不做；**平台/工具自带功能已免费解决的，不做**（先做这道验证再往下走）。

**标准三：必须答得出"比直接问豆包多了什么"。** 三种合法答案：持续自动化 / 专业深度 / 系统流程。答不出就淘汰。Agent 类优先，但不是唯一形态。

**标准四：人群二选一或交叉。** 职场人（含求职者、小业主）/ 老年人（数字鸿沟场景）。老年题材优先用高博在老年大学的一手观察。

辅助判断（运营策略）：实操教程为核心，给可照做的步骤 / 可复制的模板；认知趋势类已叫停；时令节点 + 具体人群 + 具体场景。

### 1.3 选题流水线

0. **先拉 AI 最新讯息**（§1.0，`aihot` skill），连同**素材矿**、**在途系列**三条线一起进候选池。每条候选先过**视角三问**（§1.1 末），过不了的直接丢掉、不进打分表。
1. 候选池不少于 6 条，全部进 **8 维打分**（情绪 / 传播 / 独家 / 身份 / 时效 / 传播锚点 / 可视化 / 门槛，各 1-5 分，≥30 合格，≥35 核弹），**全表亮分**，不只给头部的分。
2. 每条叠加 **风格匹配度评估**（对照 1.4 风格画像，说明哪里合、哪里不合）。
3. Top 3 按六要素展开（难题与痛点验证 / 比问豆包多了什么 / 内容核心简述 / 选择理由 / 传播锚点 / 标题候选），其余候选给一行评分 + 一句去向（排队 / 待素材 / 淘汰）。
4. 附**淘汰记录**：被淘汰的写明死因，防止复活。
5. 给出推荐排序和理由，等高博回字母拍板，**不替他决定**。
6. 高博否了全组，就按他的新反馈修正标准，**整组重跑**——不修补旧候选。

### 1.4 高博风格画像（选题匹配标尺）

- **形态**：实操教程向，读者照着能做完；拒绝认知鸡汤和功能罗列
- **视角**：第一人称真实场景（他自己的求职 / 报销 / 育儿 / 老年大学 / 房产处置），细节别人编不出来
- **语言**：小白口语化，禁黑话禁汇报腔；标题走反常识金句或强名词直给
- **结构**：系列化潜力优先（能做成"第 N 篇"的题加分，如教爸妈用 AI 系列）
- **传播**：三端适配（公众号长文 + 小红书步骤卡 + 短视频演示），有家族群 / 职场群转发链路加分
- **人群**：职场人（求职 / 办公 / 报销）+ 老年人（数字鸿沟）双池
- **赛道**：紧扣 AI 视频制作与 Agent 自动化主线，已发稿要能串成坐标轴

### 1.5 标题公式（2026-09-25 高博修正）

**✅ 可用**：强名词直给（如"Agent 实操教程：XXX"）｜福利 / 结论直说（"XX 又送 YY 了，快点来领"）｜反常识金句「你以为…其实…」｜对比反差｜自问自答｜避坑提醒。**关键点加粗，结论先行。**

**🚫 禁用（高博 2026-09-25 点名，同类一律不许）**：
- **"产品名 + 先拿它干这 N 件事"式**——把标题写成"领了 X 这 N 天，先拿它干这 3 件事""X 送你了，用它能干这 5 件事"这类**"数字 + 行动清单"复合体**。
- **一切以"……这 N 件事 / 这 N 个用法 / 这 N 招"结尾的清单式命题**，无论前面挂的是福利、工具还是教程。原话："不要再出现这样的话或同类别的意思"。
- **数字不许被拿来撑标题**。旧的"数字清单"公式作废。

**取向**：简单直接优先。标题让人一眼知道"这东西是什么、我现在能得到什么"，不绕弯、不造悬念、不堆修辞。福利 / 时令类**可以直白喊行动**（"又送 30 天会员了，快点来领"）；工具 / 教程类走强名词直给。**注意边界**：标题能喊福利，正文主体不能也只剩通知，"能带走的东西"照旧要过。

## 二、成稿阶段

### 2.1 框架先行

### 2.2 写法规范

- 口语化，人人都能懂，禁机械排比、模板句、汇报腔；小标题像说话。
- 结论先行，小白通俗版，第一人称真实视角（高博自己的场景优先当素材）。
- 关键操作写成编号步骤卡，颗粒度到「照着点就行」：**菜单名加粗、路径写全**。
- 提示词做成可直接复制的整段。
- **段与段之间空一行留呼吸感。**
- 文末附参考来源块；不引导关注 / 订阅；不写死收益承诺数字。
- 涉及填报 / 支付的环节必写安全线：**登录自己来、验证码自己过、提交自己点**。

### 2.3 迭代纪律（实战教训沉淀）

| 高博的批评 | 对应动作 |

| 「只讲单点工具用法，看完没收获」 | 拆完整难题的全链路 |
| 「太宽泛，真想学的人看不懂 123456 步」 | 每步写到点击路径颗粒度，先讲清原理再给指令 |
| 「关键设置读者不会操作」 | 高频卡点必须配图，把读者当完全小白 |
| 「截图要用真实的」 | 配图铁律（见第三节） |
| 「图片必须用实际截图，不要用生成的图」（2026-09-23） | **零自绘图铁律**（见第〇节 + 3.1）：正文任何图形只许真实截图，自绘 SVG / 生成图一律删 |
| 「文档里写了，你怎么又犯了」 | 交付前必须重读本手册对应章节，**不凭记忆执行** |

## 三、配图阶段（铁律，永久有效）

### 3.1 素材规则（1.7 加严：从"禁假界面"扩展到"禁一切自绘图"）

- **正文里每一张图，只能用真实截图。** 这条覆盖**所有**图形：不只界面图，**流程图、对比图、概念图、结构图、时间轴、自绘 SVG 一律不许出现**。
  - 1.6 及以前的漏洞：只写了"禁自己生成**界面**示意图（PIL 线框图、假 UI）"，结果自绘的"流程图 / 对比图"被当成排版混进成稿。**1.7 明确堵死：自己画的图就是自己画的图，换个形式也不行。**
- **要图，只能去拿真图**，不能去造图：拿不到就按下面的图源优先级找，找不到就给高博「自拍截图清单」。
- 截图必须穿插到文章对应步骤位置，不许文末堆素材，**不许留占位符当完成**。
- **图源优先级**：① 高博自己实拍（敏感信息先打码）→ ② 公开实测文引用并注明图源 → ③ 官方帮助中心 / 官方发布页界面图。
- 找不到图时给高博「自拍截图清单」：标明拍哪个界面、圈哪里、注意什么。**宁可该段无图，也不许自绘一张顶上。**
- 抓教程图逐张目检：**带"AI生成"水印的一律弃用**。
- **原生 HTML 排版元素（表格 / 清单卡 / 色块 / 高亮）不算图片**，不占图位也不受本规则限制——需要视觉分隔就用它们，不要用 SVG。

### 3.5 零自绘图自查（1.7 新增·交付前必跑）

1. 在成稿 HTML 里搜 `&lt;svg`：**除封面外命中即为违规**，直接删。
2. 搜 `<img`：逐个确认是不是真实截图，有没有生成图 / 素材站图混进来。
3. 搜 `示意图` / `对比图` / `流程图` / `画一张`：确认没有"我画一张给你看"的段落。
4. 通读一遍，对每一张图问一句：**"这张图能不能证明我真做过这一步？"** 答不上来 → 删。

> 无图不丢人，假图毁账号。读者照着一张假图去点，点不到，这篇就废了。

### 3.2 图文匹配三问检查

交付前对**每一张插图**人工过三问，任一问答不上来就不许交付：

1. **画面里实际是什么？** 逐张目检，图上出现的文字、标签、按钮名要看得清清楚楚（OCR 级别）。
2. **图说说的是什么？** 图说必须如实描述画面，不许暗示画面里不存在的内容（画面是 A 专家，图说不许写得像 B 专家）。
3. **图和段落主题对不对得上？** 若图只是演示机制（如"召唤流程示意"），图说必须明示「示意 / 示例」并写清图中实际对象。

**硬约束（1.6 新增）**：

- 三问任一不过 → **只能换图或删图，禁止用"示意 / 示例"标注豁免**。"示意"只允许豁免视角、排版、演示账号差异，**不允许豁免画面主体错误**（段落写 A 专家、图里是 B 专家 = 主体错误，必须换 / 删）。
- 找图验收标准：**图上 OCR 级文字与段落对象一致**（段落写职业规划师，图里必须看得见"职业规划师"字样）。
- 引用他文截图：**逐张核对画面主体**，不凭文章标题或上下文推断图的内容。
- 找不到匹配的真实截图时：宁可该段无图，或给高博自拍清单，**不凑数**。

### 3.3 证据等级写作规则

写专家 / 功能名称必须有证据等级意识：

- **实锤**（有真实界面截图 + 实测记录）→ 可写使用细节
- **官方文字提及**（官方教程 / 文档列出但无实测）→ 只按官方简介口径写，不编使用体验
- **查无实证** → 不写

禁止把转述写成亲历口吻（"简介写得很明白"这种像是自己点开看过的表述，在只有二手来源时禁用）。

### 3.4 交付前强制自检（脚本卡死）

运行 `check_article_images.py`（工作区根目录）：扫全文有无占位标记、每张引用图片是否真实存在。**任何一项不过禁止交付**，以脚本 PASS 为准。

### 4.1 封面制作（分层精修 · 2026-09-27 高博定案）

**铁律：封面必须是「AI 生成插画 + 确定性叠字」两层合成。不许再用 PIL 画纯色块交差。**

> 2026-09-27 高博原话："每次封面做得太差劲了，封面你就用那个最好的这种技能去把这个封面做做做得好看一点。"
> 当时那版封面是 PIL 画的几何色块 + 文字，**一点画面都没有**，被判不合格。手册原先只写了"Q 版暖色系插画"七个字，等于没约束，所以这次要写死。

**为什么必须分两层**：AI 生图画质好，但**写中文标题会错字**，错一个字整张封面就废。
所以——**画面交给 AI，文字永远由 PIL 精确叠加，文字层绝不经 AI 之手。**
方法论出处：`ai-content-production` 技能包的「发布级精修」(Generative Polish)，核心就是"确定性层 + 生成层分离"。

**流程**：

1. **先报备**：`ImageGen` 每张图消耗约 **5-10 积分**。动手前必须先跟高博说一声再花，不许闷声刷图。
2. **出底图（生成层）**：用 `ImageGen`，参数 `size="1536x1024"`、`quality="high"`。
   Prompt 三要素，缺一不可：
   - **主体放一侧，另一侧留大片干净负空间**（标题要叠在留白那侧）。例：主体放右、留白在左。
   - **写明「画面中绝对不要出现任何文字、字母、汉字、数字、符号、水印或标志」**。
   - **写明「画面上下边缘都是可以安全裁切的纯色渐变」**，因为后面要裁成 2.35:1。
   - 风格锚定词固定：`Q 版暖色系扁平插画` + `圆润粗描边` + `赛璐璐平涂` + `温暖治愈有生活气息`；配色奶油米白打底、温暖橘黄与珊瑚橙为主、点缀少量清澈湖蓝。
3. **裁切**：底图裁成 **2.35:1**（落 900×382）。裁切**锚定顶部**、下移余量控制在 40px 以内，保住主体完整。
   **AI 出图自带的「AI生成」角标靠裁切整条切掉；严禁涂抹、马赛克、色块遮盖**——遮盖法定标识等于伪造。
4. **加可读性遮罩**：文字那一侧铺一层「米白 → 透明」水平渐变（实心段约占画布 34%，到 62% 处全透明）。不铺的话文字压在插画上对比度不够，手机上一眼就糊。
5. **确定性叠字（精确层）**。配色基线：深蓝 `#2E6FB5` / 黄 `#F5C842` / 米白 `#FAF8F2` / 黄块上深棕字 `#3A2A00`。
   **2× 超采样排版后 LANCZOS 降采样**，文字边缘才不毛。
   一版已验证可用的起始坐标（900×382，左边距 46）：

   | 元素 | 字号 | 位置 |
   |---|---|---|
   | 黄标（栏目 / 主题标签） | 21 粗 | y=46，黄色圆角条 |
   | 主标题第一行 | 46 粗 | y=106，深蓝 |
   | 主标题第二行 | 46 粗 | y=168，黄底块 + 深棕字 |
   | 底部小字（覆盖的场景点） | 18 常规 | y=302，深灰 `#58544C` |

6. **越界自检**：脚本里打印每个元素的右边界，**超过 892（=900-8）就算超界**，回去缩字号或挪位置。不许靠肉眼判断。
7. **落盘 `output/cover.png`**，等推送脚本按 §5.2 取用。

**脚本**：`_work/gen_cover_v2.py`（分层版，含遮罩与越界自检）。
旧版 `_work/gen_cover_v1_pil_backup.py`（纯 PIL 色块版）**已废弃，不要再拿来用**。

### 5.2 目录结构（2026-09-27 实测确认，传错目录必翻车）

`wechat_push.py` 要的是**一个"文章目录"**，脚本去这个目录下按固定名字找三样东西：

| 脚本要找的 | 允许的位置 |
|---|---|
| `final.md` | `<dir>/final.md` |
| `output.html` | `<dir>/output.html` |
| 封面 | `<dir>/cover/cover-combined.png` → `<dir>/cover.png` → `<dir>/output/cover.png`（按序取第一个命中的） |

**最容易错的一步**：正文 `<img src="...">` 是**相对路径，按这个目录解析**。所以目录必须是"html 里那个相对路径的基准目录"，否则 10 张图全部上传失败、草稿里图全空。

- ✅ 本项目的实际结构：`output.html` 里写的是**纯文件名**（`01_pitu.jpg`，不带 `img/`），图也在 `output/` 下 → 传 `...\豆包P图_20260927\output`，四样东西一次性全中。
- ❌ 别传项目根目录 `...\豆包P图_20260927`：那里只有 md 源稿，`final.md` / `output.html` 都不在，图片相对路径也对不上。
- 记法：**`ls` 一下，`final.md`、`output.html`、图文件、`cover.png` 四个在同一层，那一层就是它。**

## 七、硬红线速查（1.1–1.6 沉淀，违反即返工）

### 7.1 禁用叙事腔套话清单（永久禁止）

以下句式永久禁止出现在文章里（AI 味转折模板，读者一眼假）：

- 「那段时间我想明白一件事」
- 「后来我才发现」「直到某一天」「那一刻我突然明白」「也就是从那时起」
- 一切"先讲故事再喊转折口号"的句式

**替换原则**：转折不喊口号，直接说事。口语化替换（如"说白了""其实"），或者干脆删掉转折让场景自己说话。**每篇成稿后全文扫一遍本清单。**

### 7.2 身份隐身红线（成稿硬约束）

文章里**不得透露作者的具体职业、行业年限、单位性质、就业状态**（在职 / 失业一律不写）。

读者群默认是"准备换工作的人 + 正在找工作的人"两大群，不许窄化成某一类。第一人称保留但去身份化：钩子段优先用第二人称场景（"你有没有过这种时候"），让读者对号入座；个人案例只保留"通用经历"，抹掉一切能定位到本人的信息。

### 7.3 专精工具推荐规范（独家性新来源）

「发给 AI 谁都会」不是价值，「哪个 AI 在哪件事上最强」才是。

凡是通用 AI 都能做的场景，动笔前必须调研"哪个 AI 在这件事上有特长"，文章给读者一张「场景 → 最强工具」地图 + 真实截图。

**优先顺序**：① WorkBuddy 专家中心（读者装了就有的专家系统，简历 / 面试 / 职业规划各有专精专家，截图由高博实拍打码）② 外部专精工具（须有 2026 年实测依据，注明来源）。

**反例**：只说"把简历发给 AI 让它改" = 谁都会 = 没价值。

### 7.4 痛点验证前置

选题先问"真正的难是什么、平台 / 工具自己解决了没有"。**平台已免费覆盖的功能不是痛点**（反例：求职进度提醒——各招聘平台自带，做了没价值）。痛点要挖到工具够不着的地方（正例：岗位匹配、经验迁移、动手代劳、面试陪练）。

### 7.5 Agent 是首选形态，不是硬门槛

主题是"AI 解决难题"，判断标准统一为一句话：**比直接问豆包多了什么**。

多出来的可以是三种之一：① 持续自动化（Agent / 定时任务 / 流水线）② 专业深度（数据、知识、识图、结构化产出）③ 系统流程（多步骤串联成一条路）。**占一条即成立；单次问答且无专业深度的才淘汰。**

### 7.6 人群池

① 想学 AI 的职场人 / 小业主 ② 老年人（数字鸿沟刚需：挂号、防骗、手机操作、政务办事）。高博任职老年大学，有一手场景素材，优先用。
